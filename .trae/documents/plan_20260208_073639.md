# 小红书助手前端开发计划

## 技术栈
- **前端框架**: Vue 3 + TypeScript + Vite
- **UI框架**: Element Plus
- **状态管理**: Pinia
- **HTTP客户端**: Axios
- **图表库**: ECharts
- **其他工具**: vue-clipboard3, dayjs, crypto-js

## 项目结构
```
frontend/
├── src/
│   ├── components/      # 组件
│   ├── views/          # 页面
│   ├── stores/         # 状态管理
│   ├── utils/          # 工具函数
│   ├── types/          # 类型定义
│   └── composables/    # 组合式函数
```

## 核心功能模块
1. **文案生成页面** - 支持多种类型和风格的文案生成
2. **选题推荐页面** - 智能选题推荐和分析
3. **设置页面** - API配置管理（小红书API + 大模型API）
4. **主页** - 功能导航和快速开始

## 开发阶段
1. 项目初始化和基础框架
2. 文案生成功能
3. 选题推荐功能
4. 设置功能
5. 优化和测试

## 安全特性
- API Key加密存储
- XSS防护
- CSRF防护
- 敏感信息保护
